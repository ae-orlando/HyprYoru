# Keybinds Cheatsheet (HyprYoru)

Legend: `Super` = Windows key. Workspaces 1–10 use keys `1`–`0` (`0` = workspace 10).

## Hyprland — Apps
| Key | Action |
|---|---|
| `Super + F` | Open file manager (Nautilus) |
| `Super + B` | Open browser (Chromium) |
| `Super + M` | Open music (Spotify) |
| `Super + O` | Open ODeL (Karatina e-learning) |
| `Super + A` | Open anime (Miruro) |
| `Super + C` | Open freeCodeCamp |
| `Super + Shift + C` | Open WhatsApp (web app) |
| `Super + Space` | App launcher (Rofi yoru-main) |
| `Super + Shift + Space` | Run command (Rofi yoru-run) |
| `Super + Return` | Open terminal (Kitty) |
| `Super + Shift + K` | Toggle keystroke overlay (keycast) |

## Hyprland — System / Waybar
| Key | Action |
|---|---|
| `Super + S` | Perform full system upgrade |
| `Super + R` | Reload Waybar |
| `Super + Alt + R` | Toggle Waybar |

## Hyprland — Windows
| Key | Action |
|---|---|
| `Super + Q` | Close active window |
| `Super + Shift + Q` | Quit Hyprland |
| `Super + T` | Toggle floating |
| `Super + Shift + F` | Fullscreen (maximized) |
| `Super + Alt + F` | Fullscreen (true, hides Waybar) |
| `Super + P` | Toggle pseudotile |
| `Super + Shift + Return` | Open floating mini terminal |
| `Super + h/j/k/l` | Focus left/down/up/right |
| `Super + Shift + h/j/k/l` | Move window left/down/up/right |
| `Super + ←/→/↑/↓` | Resize window (repeating) |

## Hyprland — Workspaces & Mouse
| Key | Action |
|---|---|
| `Super + 1…0` | Focus workspace 1–10 |
| `Super + Shift + 1…0` | Move window to workspace 1–10 |
| `` Super + ` `` | Toggle scratchpad (special:magic) |
| `` Super + Shift + ` `` | Send window to scratchpad |
| `Super + Scroll Down/Up` | Next / previous workspace |
| `Super + LMB drag` | Drag window |
| `Super + RMB drag` | Resize window |

## Hyprland — Media & Brightness
| Key | Action |
|---|---|
| `XF86AudioRaiseVolume` | Volume up 5% |
| `XF86AudioLowerVolume` | Volume down 5% |
| `XF86AudioMute` | Mute toggle |
| `XF86AudioMicMute` | Mic mute toggle |
| `XF86MonBrightnessUp` | Brightness up 5% |
| `XF86MonBrightnessDown` | Brightness down 5% |
| `XF86AudioNext` | Next track |
| `XF86AudioPause / Play` | Play / pause |
| `XF86AudioPrev` | Previous track |

## Hyprland — Screenshots, Lock & Misc
| Key | Action |
|---|---|
| `Super + Shift + S` | Screenshot region → clipboard |
| `Super + Print` | Screenshot full screen → clipboard |
| `Super + U` | Lock screen (hyprlock) |
| `Super + N` | Toggle night light |
| `Super + Shift + N` | Toggle notification center (SwayNC) |
| `Super + W` | Pick wallpaper + regenerate palette |
| `Super + Shift + W` | Random wallpaper + regenerate palette |

## Kitty — Windows & Tabs
| Key | Action |
|---|---|
| `Ctrl + Shift + h/j/k/l` | Focus neighboring window |
| `Ctrl + Shift + Alt + h/j/k/l` | Move window |
| `Ctrl + Shift + Enter` | New window (with cwd) |
| `Ctrl + Shift + T` | New tab (with cwd) |
| `Ctrl + Shift + O` | Show scrollback |
| `Ctrl + Shift + F` | Hints → open in Neovim |
| `Alt + 1…8` | Go to tab 1–8 |

## Kitty — Layouts
| Key | Action |
|---|---|
| `Ctrl + Shift + Space` | Next layout |
| `Ctrl + Shift + Alt + Space` | Last used layout |
| `Alt + T` | Tall layout |
| `Alt + S` | Stack layout |
| `Alt + D` | Vertical layout |
| `Alt + Z` | Toggle stack layout |
| `Alt + V` | Splits layout (bias 70) |
| `Alt + Shift + V` | Vsplit (bias 30) |
| `Alt + Shift + H` | Hsplit (bias 35) |
| `Alt + E` | Equalize |

## Zsh — Vi mode (insert)
| Key | Action |
|---|---|
| `Ctrl + A / E` | Beginning / end of line |
| `Ctrl + W` | Backward kill word |
| `Ctrl + U` | Backward kill line |
| `Ctrl + K` | Kill to end of line |
| `Ctrl + Y` | Yank |
| `Ctrl + X, Ctrl + E` | Edit command line in Neovim |
| `Ctrl + ←/→` (various) | Forward / backward word |
| `Home / End` (various) | Beginning / end of line |
| `PageUp / PageDown` | Beginning / end of history |
| `Delete` | Delete char |
| `Insert` | Quoted insert |

## Zsh — Vi mode (normal)
| Key | Action |
|---|---|
| `vv` | Edit command line in Neovim |
| `k / j` | Up / down history |

## Fzf (Zsh)
| Key | Action |
|---|---|
| `Ctrl + R` | History search |
| `Ctrl + T` | File search |
| `Alt + C` | Directory (cd) search |
